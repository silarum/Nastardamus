# Nastardamus

Telegram Mini App для символических раскладов Таро, ежедневных ориентиров, натальных толкований и совместимости.

## Продуктовые сценарии

- карта дня, закреплённая за пользователем и текущей датой;
- серия посещений без штрафующих или манипулятивных механик;
- шесть схем раскладов от одной до семи карт с персональным толкованием;
- локальный дневник, избранное и системный Share Sheet;
- натальные подсказки, совместимость по датам или двум фото;
- безопасный «Энергетический оберег» по фото и описанию тревоги — без утверждений о реальности порчи;
- магические микроэффекты при открытии и выборе карт;
- экран лицевого счёта Silarum в режиме ожидания защищённого backend: без фиктивного баланса и операций;
- Telegram haptics, адаптация под safe-area и режим уменьшенного движения.

Стартовая иллюстрация и колода хранятся в оптимизированном WebP-виде, а короткое вступление — в облегчённом MP4.

Дневник хранится только в `localStorage` текущего устройства. Секреты AI и Telegram не передаются в браузер.
Загруженные фото уменьшаются в браузере, используются только для текущего запроса и не сохраняются в дневнике.

## Локальная проверка

```bash
npm ci
npm run check
npm test
```

Для запуска интерфейса и Vercel Functions используйте `vercel dev` или любой статический сервер вместе с совместимым обработчиком каталога `api/`.

## Переменные окружения

Скопируйте `.env.example` в локальный файл окружения и задайте:

- `BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_WEBHOOK_SECRET` — секрет заголовка Telegram webhook;
- `OPENAI_API_KEY` — серверный ключ OpenAI; если он задан, используется в первую очередь;
- `OPENAI_MODEL` — модель OpenAI; по умолчанию `gpt-5-mini`;
- `OPENROUTER_API_KEY` — необязательный резервный серверный ключ OpenRouter;
- `OPENROUTER_MODEL` — модель OpenRouter;
- `OPENROUTER_VISION_MODEL` — vision-модель для фото-сценариев; по умолчанию `openrouter/free`;
- `WEB_APP_URL` — публичный HTTPS-адрес Mini App;
- `ALLOW_UNAUTHENTICATED_PREVIEW` — только для локального предпросмотра; в production оставьте `false`.

При регистрации webhook передайте тот же `secret_token`, который сохранён в `TELEGRAM_WEBHOOK_SECRET`. AI-маршрут по умолчанию принимает только подписанный `Telegram.WebApp.initData`.
Ключ OpenAI храните только в Vercel Environment Variables с включённым режимом Sensitive для Production и Preview. Не добавляйте его в GitHub, `.env.example`, `app.js` или сообщения чата.

## Текущие ограничения

- Покупка SILARUM и обмен отключены до появления серверного учёта платежей, подтверждения операций и проверяемого источника курсов. Интерфейс не показывает платёжные реквизиты и не списывает баланс.
- Персональные AI-толкования доступны только внутри Telegram с валидным `initData`; карта дня и локальный дневник работают без сети.
- Фото-сценарии носят развлекательный, символический характер: приложение не определяет личность, характер, здоровье, совместимость или сверхъестественное воздействие по внешности.
