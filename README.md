# Nastardamus

Telegram Mini App для символических раскладов Таро, натальных подсказок, фото-чтений, PalmLink и совместимости.

## Продуктовые сценарии

- единая модульная фиолетово-золотая дизайн-система из `ui-kit`;
- семь раскладов Таро — от одной карты до Кельтского креста;
- натальные подсказки и безопасные символические фото-чтения;
- PalmLink и совместное чтение двух ладоней;
- серверный лицевой счёт SILARUM без фиктивного стартового баланса;
- локальная история, системный Share Sheet и AI-помощник;
- Telegram haptics, safe-area и режим уменьшенного движения.

Стартовая иллюстрация и колода хранятся в оптимизированном WebP-виде, а короткое вступление — в облегчённом MP4.

История хранится только в `localStorage` текущего устройства. Секреты AI и Telegram не передаются в браузер. Главный интерфейс запускается одним ES-модулем `ui-kit/app.js`; прежние конфликтующие клиентские скрипты не подключаются.

## Локальная проверка

```bash
npm ci
npm run check
npm test
```

Для запуска интерфейса и Vercel Functions используйте `vercel dev` или любой статический сервер вместе с совместимым обработчиком каталога `api/`.

## Переменные окружения

Скопируйте `.env.example` в локальный файл окружения и задайте:

- `BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_WEBHOOK_SECRET` — секрет заголовка Telegram webhook;
- `OPENAI_API_KEY` — основной серверный ключ OpenAI;
- `OPENAI_MODEL` — основная модель OpenAI (по умолчанию `gpt-5-mini`);
- `OPENROUTER_API_KEY` — необязательный резервный ключ OpenRouter;
- `OPENROUTER_MODEL` и `OPENROUTER_VISION_MODEL` — резервные текстовая и vision-модели;
- `WEB_APP_URL` — публичный HTTPS-адрес Mini App;
- `ALLOW_UNAUTHENTICATED_PREVIEW` — только для локального предпросмотра; в production оставьте `false`.

При регистрации webhook передайте тот же `secret_token`, который сохранён в `TELEGRAM_WEBHOOK_SECRET`. Маршруты ответов по умолчанию принимают только подписанный `Telegram.WebApp.initData`. Ключи провайдеров используются только в серверных функциях и не передаются в браузер.

## Текущие ограничения

- Покупка SILARUM и начисления Колеса отключены до появления отдельной защищённой серверной операции. Демо-вращение явно не изменяет баланс.
- Обмен доступен только когда он включён серверной конфигурацией; заявка отправляется через `/api/wallet`.
- Персональные AI-толкования доступны только внутри Telegram с валидным `initData`; навигация и локальная история работают без сети.
